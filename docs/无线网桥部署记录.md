# MitsubishiMonitor 无线网桥部署记录

## 项目变更
- 原方案：6台PLC通过网线直连上位机
- 新方案：4台PLC通过无线网桥连接上位机，删除第5、6台设备
- 代码改动：`DeviceManagerService.cs` 设备数 6→4，`PlcConfig.cs` 采集间隔 200ms→1000ms

## 网络架构

```
                    ┌─ [从桥1] .67 ── PLC1 (192.168.1.5)
                    ├─ [从桥2] .68 ── PLC2 (192.168.1.10)
工控机 ── [主桥] .66 ┼─ [从桥3] .69 ── PLC3 (192.168.1.15)
                    └─ [从桥4] .70 ── PLC4 (192.168.1.20)
```

- 网桥型号：有人 ST508E / ST515N
- 无线模式：iPoll 3（点对多点）
- 网桥是二层透传，PLC IP地址不变

### 无线配置
- SSID：APCPE_4B35
- 密码：123456789
- 安全模式：WPA2 个人
- 网桥登录：admin / admin01

## 网桥配置步骤

### 主机改从机（多余主机再利用）
硬件完全一样，只需改软件配置：
1. 电脑网线接主机，电脑IP设 192.168.2.65
2. 浏览器打开 192.168.2.66，admin/admin01 登录
3. 网络 → IP改为 .68/.69/.70（不冲突）
4. 无线 → 工作模式改成「站点(WDS/iPoll 2/iPoll 3)」
5. SSID 填 APCPE_4B35，密码 123456789
6. 发射功率拉满
7. 保存更改

### 注意事项
- 主桥模式必须改为 iPoll 3（点对多点），否则多台从桥无法连接
- 从桥模式选「站点(WDS/iPoll 2/iPoll 3)」会自动适配主桥
- 每台从桥配好后看侧面信号灯是否亮起确认配对成功
- 网桥管理IP和PLC通信IP在不同网段，工控机网卡需设两个IP

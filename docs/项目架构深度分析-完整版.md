## 1. 项目概述

### 1.1 项目定位
**MitsubishiMonitor.Demo** 是一个基于 WPF 的工业监控系统，专门用于监控三菱 FX3U PLC 设备。

### 1.2 核心功能
- 实时监控 PLC 的 X/Y/M 点位状态
- 温度数据采集与可视化（曲线图）
- 操作日志记录与查询
- 数据导出（Excel）
- 温度异常报警
- 钉钉通知集成

### 1.3 目标用户
- 工业自动化工程师
- 生产线监控人员
- 设备维护人员

#### 4.1.2 实现类：MitsubishiPlcService


**核心特性**:
1. **双定时器采集策略**
   - X/Y/M 点快速采集：200ms 间隔
   - 温度慢速采集：10秒间隔
   - 防止重入机制（`_isReadingXY`、`_isReadingTemp` 标志）

2. **状态变化检测**
   - 保存上一次状态（`_lastX`、`_lastY`、`_lastM`）
   - 逐位比较检测变化
   - 触发 `StateChanged` 事件

3. **地址映射**
   - X点：八进制地址（X0-X7, X10-X11）
   - Y点：八进制地址（Y0-Y7, Y14-Y17）
   - M点：分段读取（M2009-M2016, M2451-M2452）
   - 温度：D12-D13（DINT，除以10）
   - 热电偶：D17-D18, D19-D20, D21-D22（DINT，除以100）

4. **错误处理**
   - 连接超时检测
   - 读取失败重试
   - 错误码 1013 自动断线

#### 4.2.3 批量写入优化（LogBufferService）

**设计目的**: 避免频繁的数据库写入操作，提升性能

**实现机制**:
1. 内存队列缓冲（`ConcurrentQueue`）
2. 定时批量写入（每5秒或累积100条）
3. 异步非阻塞写入

```csharp
public class LogBufferService
{
    private readonly ConcurrentQueue<TemperatureLog> _tempQueue = new();
    private readonly ConcurrentQueue<OperationLog> _opQueue = new();
    private readonly Timer _flushTimer;
    
    public void EnqueueTemperatureLog(TemperatureLog log)
    {
        _tempQueue.Enqueue(log);
        if (_tempQueue.Count >= 100)
            _ = FlushAsync();  // 达到阈值立即写入
    }
    
    private async Task FlushAsync()
    {
        // 批量写入数据库
        var batch = new List<TemperatureLog>();
        while (_tempQueue.TryDequeue(out var log))
            batch.Add(log);
        
        if (batch.Any())
            await _dataService.AddTemperatureLogBatchAsync(batch);
    }
}
```

**插件加载器**:

public class PluginLoader
{
    public List<IMonitorPlugin> LoadPlugins(string pluginDir)
    {
        var plugins = new List<IMonitorPlugin>();

                .Where(t => typeof(IMonitorPlugin).IsAssignableFrom(t));
            
            foreach (var type in types)
            {
                var plugin = (IMonitorPlugin)Activator.CreateInstance(type);
                plugins.Add(plugin);
            }
        }
        
        return plugins;
    }
}

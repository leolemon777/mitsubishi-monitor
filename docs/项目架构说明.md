# MitsubishiMonitor.Demo 项目架构说明

> 基于 Architecture Designer 思路整理，便于后续改动的边界与依赖清晰。

---

## 1. 项目定位与技术栈

| 维度 | 内容 |
|------|------|
| **类型** | WPF 桌面应用 (WinExe)，.NET 8.0 Windows |
| **目标** | 多台三菱 FX3U-ENET-ADP PLC 的监控：状态、温度、X/Y/M 点、操作日志、Excel 导出 |
| **通信** | HslCommunication → MelsecA1ENet（MC 协议 1E 帧，TCP 端口 5000） |
| **数据** | SQLite（EF Core 8），本地 `Data/Monitor.db` |
| **UI** | MVVM（CommunityToolkit.Mvvm）+ LiveCharts.Wpf + 自定义 Converters/Styles |

---

## 2. 高层架构（分层与数据流）

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Presentation (Views + ViewModels)                                      │
│  MainWindow → DeviceListViewModel   │  DeviceDetailWindow → DeviceDetailViewModel │
│  (6 张设备卡片 + 连接/刷新/打开详情)  │  (单设备详情：温度曲线、电压、操作日志、导出)  │
└───────────────────────┬─────────────────────────────┬───────────────────┘
                        │                             │
                        ▼                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  Application / Services                                                 │
│  DeviceManagerService (多设备编排)  │  MitsubishiPlcService (单设备PLC)   │
│  - 6 台 Device + DevicePlcWrapper   │  - Connect/ReadX,Y,M/温度/热电偶   │
│  - ConnectDevice/ConnectAll        │  - StateChanged / ConnectionState  │
│  - StateChanged → 写 DB + 今日计数  │  - 200ms XY 轮询 / 10s 温度轮询     │
│  - 5s 监控定时器（掉线检测）        │  - PlcConfig / PlcStatus            │
└───────────────────────┬─────────────────────────────┬───────────────────┘
                        │                             │
                        ▼                             ▼
┌───────────────────────────────────┐  ┌─────────────────────────────────┐
│  DataService (IDataService)        │  │  ExcelExportService             │
│  - MonitorDbContext (SQLite)       │  │  - 设备数据/温度/操作日志 → xlsx │
│  - TemperatureLog / OperationLog   │  │  - EPPlus                       │
└───────────────────────────────────┘  └─────────────────────────────────┘
```

- **入口**：`App.xaml` → `MainWindow`，DataContext = `DeviceListViewModel`。
- **主界面**：设备列表由 `DeviceManagerService.Devices`（只读集合）驱动；每张卡片对应一个 `Device`，在线状态来自各设备 `IPlcService.CurrentStatus.IsConnected`，经 5s 定时器同步到 `Device.IsOnline`。
- **详情**：点击卡片打开 `DeviceDetailWindow(device, DeviceManager)`，ViewModel 通过 `DeviceManager.GetPlcService(device.Id)` 拿到同一台设备的 `IPlcService`，订阅 `StateChanged` 做实时日志 UI；数据库写入由 `DeviceManagerService.OnPlcStateChanged` 统一完成。

## 3. 核心模块职责

### 3.1 Models（领域/展示模型）

| 类型 | 用途 |
|------|------|
| **Device** | 设备卡片展示：Id/Name/Location/IpAddress/Port、IsOnline、CurrentTemperature、HasAlert、TodayOperationCount、LastUpdateTime；计算属性 StatusDisplay/StatusColor/TemperatureDisplay；ObservableObject + NotifyPropertyChangedFor |
| **PlcConfig** | PLC 连接与采集配置：IP、端口、超时、X/Y/M/温度/热电偶地址与数量、采集间隔、温度阈值、X/Y 点中文标签字典 |
| **PlcStatus** | 实时状态：X/Y/M 数组、Temperature、ThermocoupleA/B/C、IsConnected、LastUpdateTime；INotifyPropertyChanged，含按点索引的绑定用属性（X0–X11, Y0–Y17 等） |
| **StateChangeEvent** | IO 变化事件：PointType、PointIndex、OldValue/NewValue、EventTime、Address、Description |
| **OperationLog** | 操作日志实体（DB + 列表展示）：DeviceId、LogType、PointAddress、Action、Description、LogTime；FromChangeEvent(StateChangeEvent) |
| **TemperatureLog** | 温度日志实体（DB）：DeviceId、Temperature、热电偶、RecordTime、IsAbnormal、Threshold |

### 3.2 Services（应用层）

| 服务 | 职责 | 依赖 |
|------|------|------|
| **IPlcService / MitsubishiPlcService** | 单 PLC 连接、读 X/Y/M/温度/热电偶、启停采集、ConnectionStateChanged/StateChanged | PlcConfig、PlcStatus、HslCommunication.MelsecA1ENet |
| **DeviceManagerService** | 6 台设备初始化（IP 10/15/20/25/30/35）、每台一个 MitsubishiPlcService、订阅各 StateChanged 写 DB 并更新 Device.TodayOperationCount、5s 掉线检测、ConnectDevice/ConnectAll/RefreshAll | IDataService（DataService）、Device、DevicePlcWrapper |
| **IDataService / DataService** | SQLite 初始化、TemperatureLog/OperationLog 增删查、按设备与时间范围查询、清理旧数据 | MonitorDbContext |
| **ExcelExportService** | 按设备导出温度+操作日志到 Excel | EPPlus、IDataService 通过临时 DataService 查数 |

### 3.3 ViewModels（界面逻辑）

| ViewModel | 绑定视图 | 职责 |
|-----------|----------|------|
| **DeviceListViewModel** | MainWindow（设备列表） | 持有 DeviceManagerService、Devices 集合、时钟、RefreshAll、ConnectAllDevices、单设备 ConnectDevice、OpenDeviceDetail；不自动连接（注释：由用户手动连接） |
| **DeviceDetailViewModel** | DeviceDetailWindow（单设备详情） | 当前设备、PLC 服务、订阅 StateChanged 更新 OperationLogs 与 TotalOperationCount、温度阈值编辑、时间范围筛选、LoadDataAsync（从 DB 拉日志/温度）、导出 Excel、加热棒电压/诊断/预测温度（1s 定时刷新） |

### 3.4 Views / UI 资源

| 项 | 说明 |
|----|------|
| **MainWindow.xaml(.cs)** | 设备卡片网格、标题栏、时钟；DataContext = DeviceListViewModel；无 DI，直接 new |
| **DeviceDetailWindow.xaml(.cs)** | 设备概览、总操作次数、温度报警阈值、时间范围、温度历史曲线、加热棒电压曲线；DataContext = DeviceDetailViewModel(device, deviceManager) |
| **Converters** | BoolToOnOffConverter、BoolToChineseConverter、BoolToStatusColorConverter、BooleanToVisibilityConverter、InverseBoolConverter 等 |
| **Styles** | CustomStyles.xaml、IndicatorLampStyle.xaml、CardStyle/StatCardStyle 等 |
| **Data** | MonitorDbContext：TemperatureLog、OperationLog 表；DB 路径在 exe 同目录下 Data/Monitor.db |

## 4. 关键数据流

1. **连接**  
   用户点「连接」→ DeviceListViewModel 调用 `DeviceManager.ConnectDeviceAsync(device.Id)` 或 `ConnectAllDevicesAsync()` → 对应 MitsubishiPlcService.ConnectAsync() → 成功则 StartAcquisition()，并 UpdateDeviceOnlineState(wrapper, true)。

2. **IO 变化 → 日志**  
   MitsubishiPlcService 内 200ms 定时器读 X/Y/M，与 _lastX/_lastY/_lastM 比较 → 若有变化则触发 StateChanged。  
   - DeviceManagerService 已订阅：OnPlcStateChanged(deviceId, evt) → AddOperationLogAsync(log)、Device.TodayOperationCount++。  
   - DeviceDetailViewModel 已订阅：OnPlcStateChanged → Dispatcher 内 OperationLogs.Insert(0, log)、TotalOperationCount = OperationLogs.Count。

3. **详情页初始数据**  
   DeviceDetailViewModel 构造时 LoadMockData()（温度曲线等占位）+ Task.Run(LoadDataAsync())，从 DB 按设备与 FilterStartDate/FilterEndDate 拉 OperationLogs 与温度日志，填列表与 TotalOperationCount。

4. **在线状态**  
   DeviceManagerService 每 5s MonitorDeviceStatusAsync：根据各 PlcService.CurrentStatus.IsConnected 更新 Device.IsOnline，并刷新 OfflineDevices。Device 的 StatusDisplay/StatusColor 依赖 IsOnline，通过 NotifyPropertyChangedFor 通知 UI。

## 5. 设计要点与约束

- **无全局 DI 容器**：App 未用 Host/DI，ViewModel 与 Service 均在需要处 new（如 MainWindow 中 new DeviceListViewModel，其内 new DeviceManagerService）。
- **单例语义**：DeviceManagerService 仅在 DeviceListViewModel 内创建一次，通过 DeviceManager 属性传给 DeviceDetailWindow，保证详情页与列表页共用同一批 Device 与 IPlcService 实例。
- **线程**：PLC 轮询在 Timer 线程；写 DB 在 Task.Run；UI 更新统一 App.Current.Dispatcher.Invoke。
- **PLC 协议**：FX3U-ENET-ADP、MC 协议 1E 帧、端口 5000；地址约定见 PlcConfig（X0–X11、Y0–Y17、M2553–M2554、D12 温度、D17/D19/D21 热电偶）。

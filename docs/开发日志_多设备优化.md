## 一、🔴 线程安全修复

### 1. XY 采集防重入（非原子 bool → Interlocked）
**文件**：`Services/MitsubishiPlcService.cs`

```csharp
// 改前（有竞态窗口）
private bool _isReadingXY = false;
if (!_isAcquiring || _isReadingXY) return;
_isReadingXY = true;

// 改后（原子操作）
private int _isReadingXY = 0;
if (!_isAcquiring || Interlocked.Exchange(ref _isReadingXY, 1) == 1) return;
// finally: Interlocked.Exchange(ref _isReadingXY, 0);
```

### 2. 温度定时器 async void → void + Task.Run
**文件**：`Services/MitsubishiPlcService.cs`

```csharp
// 改前（async void 异常无法捕获）
private async void OnTempTimerElapsed(...)

// 改后（安全模式）
private void OnTempTimerElapsed(...)
{
    if (Interlocked.Exchange(ref _isReadingTemp, 1) == 1) return;
    Task.Run(async () => {
        try { ... }
        finally { Interlocked.Exchange(ref _isReadingTemp, 0); }
    });
}
```

### 6. 三色灯逻辑重写（按实时温度分级）

| 条件 | 灯色 |
|------|------|

### 7. M 点读取块合并（减少 TCP 请求）
**文件**：`Services/DeviceManagerService.cs`

| 设备 | 优化前请求数 | 优化后请求数 | 节省 |
|------|------------|------------|------|
| 设备 1 | 10次 | 4次 | -60% |
| 设备 3 | 12次 | 3次 | -75% |

用 `Enumerable.Range` 生成连续 `MAddressList`，合并相邻稀疏 M 块为大块读取。  
`MAddressList` 总条目数 = 各块 `Count` 之和（严格对齐）。
